## Evidence limits and acceptance

Five routing handler probes characterized #97/#103/#104/#107/#108. For #97/#104/#108, injected ungrounded review deliberately exercised fallback; a grounded answer can bypass that branch. Three further handler probes reproduced #99/#101/#102. These use existing handler fixtures with substituted provider and transport responses, not generated-answer accuracy measurements or live service verification.

Deterministic helper checks also reproduced #98/#101/#105. Release checks established both sides of #106: Mac-only history plus a build skipped lookup, while desktop wording and an explicit latest-version request performed lookup; a separate fixture demonstrated cross-platform lexical selection. These current-code results do not prove which provider response or branch caused each historical incident. #100's candidate repair remains outside these completed audit claims.

Each repair needs a failing-before/passing-after regression, affected handler integration, relevant success/failure controls, final-diff review and required current-head checks.
